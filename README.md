# Fertem Smart Forms

Кастомный модуль форм для редакции **«1С-Битрикс: Старт»**. Не требует штатного модуля `form`: формы, поля и заявки хранятся в собственных таблицах D7.

## Возможности

- визуальный конструктор полей в административной панели;
- текст, email, телефон, textarea, select, checkbox и скрытые поля;
- сценарные поля: показ поля только при заданном значении другого поля;
- **«Тихий щит»**: honeypot, контроль времени заполнения и ограничение частоты без CAPTCHA;
- **«Черновик-помощник»**: автосохранение введённых данных в `localStorage`;
- автоматическая фиксация UTM-меток, реферера и страницы отправки;
- уведомления на несколько email-адресов;
- подписанный исходящий webhook;
- CSV-экспорт заявок и статусы обработки;
- AJAX-отправка и адаптивный шаблон.

## Установка

1. Скопируйте `local/modules/fertem.smartforms` в корень сайта.
2. В административной панели откройте **Marketplace → Установленные решения**.
3. Установите «Fertem: Умные формы».
4. Создайте форму в **Сервисы → Умные формы**.
5. Разместите компонент на странице:

```php
<?php
$APPLICATION->IncludeComponent(
    'fertem:smartform',
    '',
    ['FORM_ID' => 1, 'AJAX_MODE' => 'Y'],
    false
);
?>
```

Требования: PHP 7.4+, актуальная версия 1С-Битрикс с D7, MySQL/MariaDB.

## Webhook

При заполненном URL модуль отправляет JSON с данными заявки. Заголовок `X-Fertem-Signature` содержит HMAC-SHA256 тела запроса.

## Структура

- `lib/` — ORM и сервис обработки заявок;
- `admin/` — конструктор, список заявок и CSV-экспорт;
- `install/components/` — публичный компонент.
